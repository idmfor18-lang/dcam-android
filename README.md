# D-CAM Android

Лёгкий клиент для доступа к личной камере [camdm.pp.ua](https://camdm.pp.ua) (резервный адрес: [dcam-web.fly.dev](https://dcam-web.fly.dev)).

## Скачать приложение (APK)

👉 **[Скачать D-CAM.apk (последняя версия)](https://github.com/idmfor18-lang/dcam-android/releases/latest/download/D-CAM.apk)**

1. Откройте ссылку на Android-телефоне и скачайте файл `D-CAM.apk`.
2. Нажмите на файл для установки (при запросе разрешите установку из браузера/файлового менеджера).
3. Войдите один раз под вашим логином и паролем — сессия сохраняется в приложении.
